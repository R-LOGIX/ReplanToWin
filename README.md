⚡ ReplanToWin ユーザーガイド ⚡
受験勉強を「気合い」で戦うのは、もう終わりにしよう。
『ReplanToWin』は、精神論ではなくデータとロジックで合格を目指す受験生のための「戦略的進捗管理システム」です。

🚀 このアプリの核心（コア）
 1. 進捗に応じた「AI自動再構築」
   予定が崩れた瞬間に、今の進捗から試験日に間に合う「最適解」をAIが計算し直します。計画倒れの罪悪感はもう不要です。
 2. 「周回」を前提とした設計
   成績を上げる唯一の方法は復習です。このアプリは最初から、教材を何周もすることを前提にスケジュールを組み上げます。

🛠 使いかたの 4 ステップ
【STEP 1：教材をシステムに登録する】
「1. 教材登録」タブから、使用する参考書や問題集を入力します。
🔹 ページ範囲指定：問題集の「1〜200ページ」を管理
🔹 合計件数指定：単語帳の「2000語」を管理
🔹 項目リスト指定：「プリントA」「過去問」など特定の名前で管理
🔹 教材別スケジュール：月水金は数学、土日は英語…など、教材ごとに学習する曜日を自由に設定できます。
【STEP 2：AI計画を生成する】
ホーム画面の「AI学習計画を生成する」ボタンをタップ。
試験日から逆算して、AIが「今日やるべきこと」を日割り計算します。
【STEP 3：進捗を報告する】
「2. 進捗入力」タブで、やった分を数字で入力します。
「1周目は完了、2周目はここまで」と、周回ごとの進捗を直感的に管理できます。
【STEP 4：計画を再構築する（ここがイチオシ！）】
予定より遅れてしまった時、あるいは早く進んだ時。
ホーム画面の「AIが計画を再構築」ボタンを押してください。
現在の進捗データから、試験日に間に合わせるための「新しいノルマ」をその場で再計算します。

💡 戦略的アドバイス
✅ 「計画は崩れるもの」と割り切る
計画がズレたら即座に「再構築ボタン」を押す。それがこのアプリの正しいムーブです。
✅ 復習を仕組み化する
最初から目標周回数を「3周」や「5周」に設定しましょう。AIが自動的に、復習を含めた全工程を試験日までに収めます。
✅ 集中力を引き出す UI
余計な装飾を省いたダークモードが、あなたの没入感を高めます。
根性論を捨て、ReplanToWinで学習を科学的にコントロールせよ。
努力を結果に変える「仕組み」をその手に。🏆
